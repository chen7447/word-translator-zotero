# 单词翻译 Word Translator for Zotero

## v5.3.1 正式版更新说明

- 修复并优化 Zotero 阅读器中的划词翻译与快捷键交互。
- 改进单词卡片的即时显示和翻译结果更新体验。
- 优化单词本面板刷新、排序及字体大小调整后的显示一致性。
- 改进 Item Pane 标题、侧栏提示和图标显示。
- 增强与其他 Zotero 阅读器插件共存时的稳定性，避免影响其他插件的划词菜单按钮。
- 更新版本与自动更新信息，正式发布 v5.3.1。

## 安装

1. 从 [Releases](https://github.com/chen7447/word-translator-zotero/releases) 下载 `wordtranslator-5.3.1.xpi`。
2. 打开 Zotero，进入“工具 → 插件”。
3. 将 XPI 文件拖入插件管理器，或通过齿轮菜单选择“从文件安装插件”。
4. 安装后按提示重启 Zotero。

## 使用

在 PDF 阅读器中选中英文单词或短语，然后点击“添加单词并翻译”，即可翻译并保存到当前条目的单词本。插件支持快捷键、自动翻译、多 API 配置、自定义提示词及单词本管理。

## 系统要求

- Zotero 7.9.9 或更高版本
- 支持 Zotero 7、8、9 及后续兼容版本
- 一个可用的翻译 API 服务及对应 API Key
