# 单词翻译 Word Translator for Zotero

一个面向专业英文文献阅读的 Zotero 插件。

在 PDF 阅读器中选中英文单词或短语后，可以通过弹出菜单的按钮或快捷键将内容翻译为中文，并保存到当前条目的单词本中。

支持 OpenAI 兼容接口、DeepSeek 官方接口以及其他兼容 OpenAI Chat Completions 格式的中转服务。

---

## 功能特点

- PDF 阅读器划词后显示“添加单词并翻译”菜单项。
- 调用大语言模型翻译英文单词或短语。
- 支持 OpenAI 兼容接口、DeepSeek 和自定义接口。
- 支持配置多个 API 服务，并在右侧单词本面板中快速切换。
- 支持自定义系统提示词、用户提示词或全局提示词。
- 支持 {{word}} 占位符，将自动替换为选中的文本。
- 支持选中文本后自动翻译并加入单词本。
- 支持“先选区后按绑定键”快捷键。
- 支持“按住快捷键划词翻译”。
- 支持自定义键盘组合键和鼠标按键录制。
- 单词本支持逐条删除和全部清空。
- 支持调节单词本字体大小。
- API 配置和单词本数据保存在本地 Zotero 配置目录中。

---

## 系统要求

- Zotero 7.9.9 或更高版本
- 支持 Zotero 7、8、9 及后续兼容版本
- 一个可用的翻译 API 服务及对应 API Key

## 安装

1. 从项目 Release 页面下载最新版 .xpi 文件。
2. 打开 Zotero。
3. 进入：

   `	ext
   工具 → 插件
   `

4. 将 .xpi 文件拖入插件管理器，或点击右上角齿轮按钮并选择“从文件安装插件”。
5. 安装完成后，建议重启 Zotero。

插件文件示例：

`	ext
wordtranslator-4.5.0.xpi
`

---

## 首次配置

安装后打开：

`	ext
编辑 → 设置 → 单词翻译 Word Translator
`

不同操作系统中菜单名称可能略有不同。

### 添加翻译 API

在“翻译 API”区域点击：

`	ext
+ 添加服务商
`

填写以下内容：

| 配置项 | 说明 |
|---|---|
| 名称 | 用于区分不同 API 服务，例如“OpenAI 官方”或“中转站 A” |
| 服务商 | OpenAI 兼容、DeepSeek 或自定义 |
| API URL | API 基础地址 |
| API 密钥 | 对应服务商提供的 API Key |
| 模型名称 | 要调用的模型名称 |

常见配置示例：

#### OpenAI 官方

`	ext
API URL: https://api.openai.com/v1
模型: gpt-4o-mini
`

#### DeepSeek 官方

`	ext
API URL: https://api.deepseek.com
模型: deepseek-chat
`

#### OpenAI 兼容中转站

`	ext
API URL: 以服务商提供的基础地址为准
模型: 以服务商支持的模型名称为准
`

填写完成后，可以使用：

- “测试”按钮测试当前配置；
- “获取模型”按钮从 API 获取可用模型列表；
- “保存”按钮保存当前服务。

配置多个 API 后，可以在单词本右上方的下拉列表中切换当前使用的 API。

## 基本使用

1. 在 Zotero 中打开 PDF。
2. 用鼠标选中英文单词或短语。
3. 在弹出的阅读器工具栏中点击：

   `	ext
   添加单词并翻译
   `

4. 插件会立即在右侧 Item Pane 的单词本中创建卡片。
5. 卡片首先显示：

   `	ext
   单词 -- 翻译中…
   `

6. API 返回结果后，卡片会自动更新为：

   `	ext
   单词 -- 中文译文
   `

如果当前条目没有打开右侧单词本面板，可以在 Zotero 的 Item Pane 中启用“单词本”面板。

---

## 自动翻译

在偏好面板中开启：

`	ext
选中文本后自动翻译并加入单词本
`

开启后，选中 PDF 文本时会自动：

1. 获取选中文本；
2. 调用当前 API 翻译；
3. 将单词和译文加入当前条目的单词本。

开启自动翻译后，不需要再点击“添加单词并翻译”按钮。

如果希望手动选择要加入的单词，应关闭自动翻译。

# 快捷键

插件提供两套不同的快捷键功能。

## 功能一：绑定“添加单词并翻译”快捷键

这是“先选区，再按键”的模式。

### 使用流程

`	ext
先选中单词
    ↓
按下绑定键
    ↓
立即添加单词并翻译
`

触发时不需要等待按键松开。

### 开启方式

在设置中开启：

`	ext
绑定「添加单词并翻译」快捷键（先选区后按绑定键触发）
`

支持以下绑定方式：

- Ctrl
- Alt
- Shift
- 自定义绑定按键

自定义快捷键可以通过双击输入框进行录制，例如：

`	ext
Ctrl+Enter
Alt+Z
Ctrl+Alt+T
`

### 示例

假设绑定键设置为 Ctrl：

1. 在 PDF 中选中 mitochondria；
2. 按下 Ctrl；
3. 插件立即执行“添加单词并翻译”。

该模式不要求按住快捷键划词，适合已经完成选区后再触发翻译的场景。

---

## 功能二：快捷键-划词翻译

这是“按住快捷键，同时划词”的模式。

### 使用流程

`	ext
按住快捷键
    ↓
划选文本
    ↓
弹出工具栏
    ↓
自动添加单词并翻译
`

翻译发生在选区弹出工具栏出现时，而不是在快捷键 keydown 的瞬间执行。

### 预设快捷键

在设置中开启：

`	ext
快捷键-划词翻译
`

预设组合键支持：

- Ctrl
- Alt
- Ctrl + Alt

例如选择 Alt：

1. 按住 Alt；
2. 用鼠标连续划选多个单词；
3. 每次弹出选区工具栏时，插件都会自动添加并翻译；
4. 松开 Alt 后，本次快捷键会话结束。

同一次按住操作期间可以连续划词翻译多个单词。

### 自定义快捷键

也可以开启：

`	ext
自定义快捷键
`

然后双击输入框录制快捷键，例如：

`	ext
Ctrl+D
Alt+Z
Ctrl+Alt+T
`

“快捷键-划词翻译”和“自定义快捷键”是互斥选项，两者只能启用其中一个。

### 注意事项

“快捷键-划词翻译”和“先选区后按绑定键”属于不同功能。

为了避免触发冲突，两个功能不要使用相同的快捷键。例如：

`	ext
快捷键-划词翻译：Alt
先选区后按绑定键：Ctrl
`

或者：

`	ext
快捷键-划词翻译：Alt
先选区后按绑定键：Ctrl+Enter
`

设置面板检测到两个功能使用相同快捷键时，会提示快捷键冲突，并阻止保存。

---

## 快捷键功能对比

| 功能 | 操作顺序 | 触发时机 | 适用场景 |
|---|---|---|---|
| 添加单词并翻译快捷键 | 先选区 → 按绑定键 | keydown 时立即触发 | 已经选好文本后手动触发 |
| 快捷键-划词翻译 | 按住快捷键 → 划词 | 选区工具栏出现时触发 | 连续划词并自动翻译 |
| 自动翻译 | 直接划词 | 选区出现后自动触发 | 不需要任何快捷键 |

## 自定义提示词

插件支持两种提示词模式。

### 系统提示词 + 用户提示词

分别设置：

- 系统提示词（System）
- 用户提示词（User）

用户提示词中可以使用：

`	ext
{{word}}
`

例如：

`	ext
请将以下英文单词或短语翻译为专业中文：{{word}}
`

插件会将 {{word}} 自动替换为选中的文本。

### 全局提示词

也可以选择：

`	ext
全局提示词
`

将全部提示内容合并到一个输入框中。

无论使用哪种模式，均可以点击“恢复默认”恢复默认提示词。

---

## 单词本

单词本显示在 Zotero 右侧 Item Pane 中。

每个单词以卡片形式显示：

`	ext
英文单词 -- 中文译文
`

支持：

- 单条删除；
- 清空当前条目的全部单词；
- 调整字体大小；
- 切换当前翻译 API；
- 翻译过程中显示“翻译中…”；
- 翻译失败时显示“翻译失败”。

单词本数据按照 Zotero 条目分别保存，不同 PDF 条目的单词互不混淆。

---

## 字体大小

可以在偏好面板的“外观”区域调整字体大小。

支持范围：

`	ext
9–24 px
`

也可以直接在单词本面板顶部使用放大和缩小按钮调整。

默认字体大小：

`	ext
13 px
`

## 数据存储

插件会在 Zotero profile 目录下创建：

`	ext
wordtranslator/
├── api-config.json
└── words/
    ├── <itemID>.json
    └── ...
`

其中：

- pi-config.json：保存 API 配置、快捷键、提示词及其他插件设置；
- words/<itemID>.json：保存对应 Zotero 条目的单词本；
- wordtranslator-debug.log：保存插件调试日志。

可以在偏好面板的“保存目录”区域查看并打开数据目录。

### 数据隐私

- API Key 保存在本地 Zotero 配置目录中；
- 选中的文本只会发送到当前配置的 API 服务；
- 插件不会将 API Key 或单词本上传到插件作者的服务器；
- API 服务商可能按照其自身隐私政策记录请求内容，请根据实际服务商的政策使用。

建议不要将 API Key 提交到 GitHub、论坛或其他公开位置。

## 常见问题

### 1. 点击“测试”失败

请检查：

- API URL 是否正确；
- API URL 是否为基础地址，而不是完整的 /chat/completions 地址；
- API Key 是否有效；
- 模型名称是否正确；
- 当前网络是否可以访问该服务；
- 服务商是否支持 OpenAI Chat Completions 格式。

一般情况下，API URL 应填写基础地址，例如：

`	ext
https://api.openai.com/v1
`

插件会自动请求：

`	ext
/chat/completions
`

---

### 2. 获取模型列表失败

请确认：

- API URL 是否支持 /models 接口；
- API Key 是否有读取模型列表的权限；
- 中转站是否兼容 OpenAI 的模型列表接口。

部分服务商不提供模型列表接口。此时可以直接手动填写模型名称。

---

### 3. 划词后没有显示菜单

请检查：

- 插件是否已启用；
- 是否在 Zotero PDF 阅读器中操作；
- 选中的文本是否为空；
- 选区文本是否过长；
- 阅读器是否需要重新打开；
- 是否存在其他插件修改了选区工具栏。

必要时可以重启 Zotero 后重新打开 PDF。

---

### 4. 快捷键没有触发

请检查：

- 对应快捷键功能是否已开启；
- 快捷键是否与另一个功能冲突；
- 是否按住了正确的组合键；
- 自定义快捷键是否已经成功录制；
- 是否在 PDF 阅读器区域内操作；
- 是否需要重新打开当前 PDF 阅读器。

“快捷键-划词翻译”和“自定义快捷键”只能启用其中一个。

---

### 5. 快捷键功能互相触发

请确保以下两个功能没有使用相同按键：

`	ext
快捷键-划词翻译
`

和：

`	ext
绑定“添加单词并翻译”快捷键
`

推荐为两个功能设置不同的按键，例如：

`	ext
快捷键-划词翻译：Alt
添加单词并翻译：Ctrl
`

或者：

`	ext
快捷键-划词翻译：Alt
添加单词并翻译：Ctrl+Enter
`

设置面板检测到两个功能使用相同快捷键时，会提示快捷键冲突，并阻止保存。

---

### 6. 单词本没有立即显示

插件会自动刷新 Item Pane。如果仍未显示，可以尝试：

1. 切换到其他 Zotero 条目，再切回当前条目；
2. 点击单词本面板中的刷新按钮；
3. 关闭并重新打开 Item Pane；
4. 重启 Zotero。

---

### 7. 翻译显示“翻译失败”

请检查：

- API 是否配置正确；
- API Key 是否过期；
- 模型是否可用；
- 服务商是否返回了符合 OpenAI 格式的响应；
- API 是否有余额或调用额度；
- 网络连接是否正常。

详细错误信息可以查看 Zotero profile 目录中的：

`	ext
wordtranslator-debug.log
`

## 开发说明

主要文件结构：

`	ext
manifest.json
bootstrap.js
content/
├── preferences.xhtml
├── preferences.js
├── scripts/
│   ├── addon.js
│   ├── storage.js
│   └── ...
└── icons/
locale/
└── zh-CN/
    └── addon.ftl
`

主要模块：

| 文件 | 作用 |
|---|---|
| manifest.json | 插件名称、版本号、兼容范围和更新地址 |
| ootstrap.js | 插件启动、关闭及 Chrome 资源注册 |
| content/scripts/addon.js | 核心功能、PDF 划词、快捷键、翻译和单词本 |
| content/scripts/storage.js | API 配置和单词本的本地文件存储 |
| content/preferences.js | 偏好面板逻辑 |
| content/preferences.xhtml | 偏好面板页面 |
| locale/zh-CN/addon.ftl | Zotero 界面本地化文本 |

### 重新打包

进入构建目录后执行：

`powershell
.\package.ps1
`

或者将插件源码目录直接压缩为 ZIP，再将扩展名改为：

`	ext
.xpi
`

压缩包根目录必须直接包含：

`	ext
manifest.json
bootstrap.js
`

不能在外层额外嵌套一个源码目录。
