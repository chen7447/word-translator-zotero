## 问题判断
截图显示 Item Pane 主体和图标已经正常，失败只剩两个本地化文本：

- 箭头 1：Item Pane header 的标题没有显示“单词本”；
- 箭头 2：右侧 sidenav 图标悬停没有显示“单词翻译”。

当前 API 使用 `header.l10nID`/`sidenav.l10nID` 已正确，但项目自定义的 ID 为 `wordtranslator-pane-header` 和 `wordtranslator-pane-sidenav`。参考 Zotero 插件使用的稳定约定是：

```text
<addonRef>-itemPaneSection-header
<addonRef>-itemPaneSection-sidenav
```

并在：

```text
locale/<locale>/<addonRef>-mainWindow.ftl
```

中定义对应消息。当前项目同时在 `addon.ftl` 和 `wordtranslator-mainWindow.ftl` 重复定义旧 ID，可能导致 Item Pane 找不到或加载到错误的消息。

## 修复方案
1. 将 `addon.js` 中 Item Pane 注册的 ID 改为：
   ```js
   header: {
     l10nID: "wordtranslator-itemPaneSection-header",
     icon: "chrome://wordtranslator/content/icons/favicon.png",
   },
   sidenav: {
     l10nID: "wordtranslator-itemPaneSection-sidenav",
     icon: "chrome://wordtranslator/content/icons/favicon.png",
     orderable: false,
   },
   ```
2. 更新专用主窗口本地化文件：
   - `locale/zh-CN/wordtranslator-mainWindow.ftl`
   - `locale/en-US/wordtranslator-mainWindow.ftl`
   使用与参考插件一致的消息 ID：
   ```ftl
   wordtranslator-itemPaneSection-header =
       .label = 单词本
   wordtranslator-itemPaneSection-sidenav =
       .tooltiptext = 单词翻译
   ```
3. 从通用 `locale/*/addon.ftl` 删除旧的 Item Pane 重复 key，避免同一 Fluent ID 在不同 bundle 中产生冲突；保留其他偏好设置文案不变。
4. 版本提升到 `5.1.8`，确保 Zotero 识别为新修复包。
5. 运行 `node --check addon.js`，再用 `build/package.ps1` 打包 `wordtranslator-5.1.8.xpi`。
6. 静态验证 XPI：
   - manifest 版本为 5.1.8；
   - `addon.js` 使用新的两个 l10nID；
   - XPI 包含两个 `wordtranslator-mainWindow.ftl`，且消息 ID/属性正确；
   - `addon.ftl` 不再含旧的 Item Pane key。

## 预期
安装 5.1.8 并完全重启 Zotero 后，箭头 1 的标题应显示“单词本”，箭头 2 的图标悬停 tooltip 应显示“单词翻译”。本次不改动面板主体渲染、图标文件或数据逻辑。
